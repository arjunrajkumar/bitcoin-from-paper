# Development approach

- Build in small, agreed steps, discussing each part before implementing it.
- During the initial implementation, use the whitepaper and early mailing-list and forum discussions as references, without reading or reusing Bitcoin implementation source code.
- First build using our own solutions. Comparing with the actual Bitcoin code and improving the prototype is a later phase, to begin when the user chooses to move to it.
- Make our own implementation choices explicit where the references leave details open.
- Verify meaningful behavior as the prototype grows.

Compatibility with the existing Bitcoin network is not currently a goal.
